# Product line — ready-to-list digital products

Hand-written flagship products for the Nichesmith side hustle, structured to match
the app's Prompt Pack format. Each file contains the full product **and** its
sales copy (title, price, description, tags, blurb, launch roadmap).

To ship one with no terminal: open the file, copy it into Google Docs or Canva,
add a branded cover, export a PDF, and upload that PDF as the digital download.

| Loan Officer AI Prompt Pack | Mortgage pros | $19 | [loan-officer-ai-prompt-pack.md](./loan-officer-ai-prompt-pack.md) |
| **Real Estate + Mortgage Bundle** | Both (cross-referring) | **$29** | sell both files together |

**The bundle is the hero SKU.** Realtors and loan officers refer each other, so
listing both singles plus a discounted 2-pack lets buyers self-select up and
encourages each to recommend the other pack to their partner.
